# Talent Acquisition & Employer Branding portfolio

Live page: https://lesaullianachmadargito.github.io/talent-branding-portfolio/

A single-page portfolio for a Talent Acquisition & Employer Branding (HR) internship application. The header works as
tabs: each one switches the page to its own view (Overview, Recruitment, Employer Branding, Administration, HR Learning),
with its own colour, faded background photo and layout. Views are addressable by hash, for example `#admin`, and the
browser Back button works between them. Without JavaScript the five views simply stack on one page.

## What is here

- `index.html` - the whole site (HTML, CSS and a small script; no build step).
- `assets/img/` - my own photos, certificates and screenshots, compressed for the web.
- `assets/files/intern-intake-tracker-illustrative.xlsx` - the intake-tracker work sample, with invented applicants.

## Notes

- The two work samples (the intake tracker and the four-week content plan) are drafts built from public information.
  All applicant data in the tracker is illustrative: IDs only, placeholder emails, no real people.
- This portfolio is independent and not affiliated with or endorsed by any company named in it.
- Student ID numbers are hidden on the certificates and the signature is cropped from the recommendation letter.
- The page carries `noindex`, so search engines are asked not to list it.
